## 预先固定的规则

无延续退出：入场4根15m K线后，期间最高价浮盈<0.5R，且最新收盘扣费后收益<=0R，下一根开盘退出。否则仍按4小时退出。

盈利延续退出：16根15m K线后，最新收盘扣费后收益>=0.5R且高于4根之前收盘价，继续持仓。从第17根开始，收盘<=最新4根收盘均价，下一根开盘退出；最长32根（8小时）。原结构止损始终优先。这并不是无限期持有，也不是另加一个止盈价。

## 稳定性和结论边界

无延续规则在前50天组合净利润比基准少0.54U，后50天多23.72U；改善并非两个时段一致。延长规则前50天少32.19U，后50天多29.00U，同样不稳定。两段都已被研究过，不能称为OOS。

胜率下降不一定代表规则更差：无延续退出把部分大亏变小亏，同时把部分迟来的盈利也变成小亏。这个版本的平均盈利约1.04R、平均亏损约-0.39R，基准分别约0.87R、-0.65R；但是否可重复仍不明确。

此轮支持继续验证无延续退出，而不支持立刻上线或继续在同一批数据上寻找最优小时数。当前延长规则暂未展示价值，也不能推广为所有“让利润奔跑”方法都无效。

局限：当前标的池回看历史存在选池/幸存者偏差；固定确认入场是简化策略，未完整复现生产分级/Rescue/动态退出。没有浮亏回撤、资金费率、真实撮合和强平模拟。15m OHLC不能恢复止损根内部路径。新取的短窗口能复现旧交易摘要，但没有声称完整历史行情哈希一致。
