# Tide 入场过滤实验 — 2026-09-11

结论：信号前缩量过滤在本轮探索性账户重放中改善收益与回撤，值得独立验证；1H/4H双下跌过滤减少回撤但未提高总收益。尚未修改生产程序。

区间2026-06-01至2026-09-09，原232个有效山寨币池的191个确认候选。原始触发K线开盘之前的指标来自已归档行情。两条过滤分别测试，未叠加；原始入场、结构止损、固定4小时退出、成本和资金规则均不变，也未加入前一轮的1小时无延续退出。

缩量规则：信号前最近6小时的平均成交量 <= 此前18小时平均成交量的0.5倍。0.5是本次实验运行前固定的整数比例，不是优化所得最佳阈值；这个研究方向已经受本期历史数据启发，因此仍不是样本外测试。

趋势规则：信号前已完成的1H和4H数据中，两个周期均为SMA50<SMA200。

## 缩量改善来源

原134笔中被过滤100笔；过滤掉赢家利润346.49U，同时避开亏损361.19U，固定原交易名单净改善只有14.70U。释放仓位后新接纳8笔，合计盈利76.15U，构成完整账户总改善90.85U的主要部分。这8笔全部位于6月26日和7月1日，因此不能把总改善完全归因于每笔信号质量提升。

缩量规则仍删掉原最大5笔赢家中的3笔，合计104.40U。它保留了AVAAI盈利75.21U。缩量账户去掉自身最大5笔赢家后，剩余已成交交易PnL为+90.43U；这是尾部敏感性诊断，没有重新释放或替换仓位。

## 稳定性

- 前50天：基准+112.73U，缩量+172.03U（32笔），趋势+132.58U。
- 后50天：基准+51.64U，缩量+83.18U（仅10笔），趋势+21.91U。缩量后半段的AVAAI单笔贡献75.21U，收益集中明显。
- 删除候选最多的两天（2026-06-26和2026-07-01）再重放：基准+80.51U，缩量+150.47U（29笔），趋势+49.36U。缩量的改善方向仍存在。

各时段独立以1000U重放；前后半段早已被研究过，不能称为未见验证。所有结果都是事后启发的探索性结果，样本小、同币和同一天收益相关、当前标的池存在幸存者/选池偏差。当前结果支持冻结缩量候选规则继续验证，不能直接承诺上线后获得25.52%收益。
