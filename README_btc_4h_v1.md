# BTC 4H 下一根K线方向回测 v1

这个版本检验一个非常明确的问题：只使用一根4H K线开盘前已经确定的信息，能否预测该4H K线最终上涨还是下跌，并在扣除交易成本后获得样本外优势。

## 规则

- 信号时间：上一根4H K线收盘、新一根开盘时。
- 入场：新4H K线开盘价。
- 离场：同一根4H K线收盘价，无条件平仓。
- 方向：模型上涨概率高于阈值时做多，低于对称阈值时做空，中间不交易。
- 默认成本：完整一笔交易12 bps，即0.12%，包含开仓、平仓手续费及预估滑点，可自行修改。
- 数据：Binance USDT-M BTCUSDT 4H永续合约K线。

## 初版特征

初版共23项，只包含开盘时已经知道的数据：前1/2/3/5/10根累计收益、前10根红绿比例、实体强弱、上下影线、ATR标准化振幅、成交量、EMA20/50位置和斜率、布林带位置和宽度、RSI及短期波动率。

模型使用 Logistic Regression。它不是在全部历史上训练后再回测，而是先用过去数据训练，只预测之后的一段；每180根K线重新训练一次。因此输出的 `oos_predictions.csv` 均为样本外预测。

## GitHub / Railway 运行

```bash
pip install -r requirements_btc_4h_v1.txt
python btc_4h_next_candle_v1.py
```

自定义测试：

```bash
python btc_4h_next_candle_v1.py --start 2020-01-01 --round-trip-bps 12 --output btc_4h_v1_results
```

输出：

- `summary.csv`：各基准及概率阈值的净表现。
- `oos_predictions.csv`：每根样本外K线的预测概率、实际涨跌和全部特征。
- `config.json`：本次参数和特征清单。

## 首先看哪些结果

不要先看累计收益，先按以下顺序判断：

1. `avg_net` 是否在55%、57.5%、60%等相邻阈值持续为正，而不是只有某一个阈值偶然突出。
2. `profit_factor` 是否稳定高于1，而非依赖少数极端行情。
3. `trades` 是否足够，阈值提高时净期望是否有合理改善。
4. `max_drawdown` 与 `worst_mae` 是否可接受。固定收盘离场不代表持仓途中没有巨大逆向波动。
5. 与 `always_long`、前一根延续、前一根反转三个简单基准相比，模型是否真的更好。

此版本不应直接连接实盘，也不应用50倍杠杆。只有在按年份、季度及市场状态进一步拆分后仍稳定，才值得进入v2验证。
